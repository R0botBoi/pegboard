# Pegboard

Click pegs on a grid to wrap a rubber band around them. Make tangent-line forms and export them as SVG or PNG.

**Live site:** https://cwchoi46.github.io/pegboard/

Keys: <kbd>D</kbd> <kbd>F</kbd> <kbd>E</kbd> tools · <kbd>R</kbd> random · <kbd>N</kbd> new form · <kbd>Ctrl/⌘ Z</kbd> undo
